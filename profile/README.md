## AI-Assisted Astronomy Taskforce

Amateurs and students using AI-assisted tools to search public survey data (mainly TESS) for eclipsing binaries,
triples, quadruples and circumbinary planets, and building demos that make that work easier to see.

An independent community project, not run or endorsed by NASA or any mission team.

**Start here**

- [**hub**](https://github.com/aiassistedastronomytaskforce/hub): shared candidate registry, search coverage,
  benchmark set, vetting rules, data formats and the [project list](https://github.com/aiassistedastronomytaskforce/hub/blob/main/PROJECTS.md)
- [**project-template**](https://github.com/aiassistedastronomytaskforce/project-template): start every new repo from this
- [Discussions](https://github.com/aiassistedastronomytaskforce/hub/discussions): questions, ideas, coordination
- [How the org works](https://github.com/aiassistedastronomytaskforce/.github/blob/main/GOVERNANCE.md) ·
  [Contributing](https://github.com/aiassistedastronomytaskforce/.github/blob/main/CONTRIBUTING.md) ·
  [Code of Conduct](https://github.com/aiassistedastronomytaskforce/.github/blob/main/CODE_OF_CONDUCT.md)

**Repo prefixes:** `pipeline-` searches · `demo-` interactive demos · `tool-` utilities · `data-` datasets ·
`paper-` write-ups
