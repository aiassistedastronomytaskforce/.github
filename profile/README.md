## AI-Assisted Astronomy Taskforce

Amateurs, students and professionals using AI tools to do astronomy with public data: searches, candidates, demos,
tools and ideas, shared in one place so people can build on each other's work.

An independent community project, not run or endorsed by NASA or any mission team.

- [**hub**](https://github.com/aiassistedastronomytaskforce/hub) (members only): personal folders, candidate notes,
  the project list and Discussions. Start here.
- [**project-template**](https://github.com/aiassistedastronomytaskforce/project-template): start new repos from this.
